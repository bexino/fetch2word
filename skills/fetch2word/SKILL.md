# fetch2word：公众号推文 → 模板化 Word

## 何时使用

- 用户给一批 `mp.weixin.qq.com/s/...` 链接，要求转成 Word
- 要求套用**固定版式**（页边距、字号、标题写法一致）
- 要求图片内嵌，但**不要 gif 装饰、不要低清小图标、不要空行**
- 要求文件名 `yyyy.mm.dd(标题).docx` 并归到产出目录

**不适用**：需要改写正文内容、需要保留音频/视频/投票等互动元素、非公众号站点。

## 版式：内置，无需准备模板

模板随 skill 分发，位于 `assets/template.docx`，脚本默认使用它。**不需要**在项目里放 `模板/` 目录，也不需要传 `--template`。

这份模板已脱敏：机构名统一为「某某职业学院 / 某某学院」，人名统一为「张某某」式，配图为同尺寸占位图；**页面尺寸、页边距、段落格式、字号字重、图片位置与尺寸与原始模板逐项一致**。

只有确实要换版式时才用 `--template <path>` 覆盖——那是例外，不是常规动作。

## 目录约定（禁止写死绝对路径）

| 用途 | 位置 | 说明 |
|---|---|---|
| 链接清单 | `链接/<月份>.txt` | 一行一个 URL，可含「排序：从旧到新」提示行 |
| 产出 | `产物/<月份>/` | 由 `--out` 指定 |

## 输出命名（固定，不可调）

```
文件名：yyyy.mm.dd(Title).docx
```

- `yyyy.mm.dd` 取文章发布日期（`var createTime`），**不是**运行日期
- `Title` 取文章标题，**去掉栏目前缀**（`公示||xxx` → `xxx`），分隔符用半角括号
- 标题中的 Windows 非法字符 `\ / : * ? " < > |` 会被剔除
- 超过 60 字的标题截断
- 该规则写死在 `safe_name()` 里，不提供参数开关；`check_output.py` 会用
  `^\d{4}\.\d{2}\.\d{2}\(.+\)\.docx$` 校验，不匹配即判不合规

示例：`2025.10.11(机电与建筑工程学院2025年拟“推优”入党学生名单公示).docx`

## 快速开始

```bash
python -m pip install python-docx beautifulsoup4 lxml pillow

python <skill>/scripts/wx2docx.py \
  --links "链接/10月.txt" \
  --out "产物/10月"
```

| 参数 | 默认 | 作用 |
|---|---|---|
| `--column` | `学院动态` | 标题无栏目前缀时补的前缀；`""` 不补 |
| `--date-note` | `（发出日期）` | 日期后的标注；`""` 只留纯日期 |
| `--sort` | `auto` | 读清单里的排序提示；可 `asc`/`desc`/`none` |
| `--keep-gif` | 关 | 保留 gif |
| `--no-heading` | 关 | 关闭小标题识别，全部按正文输出 |
| `--min-px` | 200 | 最长边低于此值视为装饰图标 |
| `--min-area` | 40000 | 像素面积低于此值视为低清装饰图 |
| `--workers` | 8 | 并发数 |
| `--cache` | 系统临时目录 | 保留中间产物便于复跑排错 |
| `--template` | 内置 | 仅特殊情况下覆盖版式 |

产出：docx + `_manifest.csv`（文件名 / 日期 / 标题 / 内嵌图数 / 跳过数 / 跳过明细 / 原文链接）。

## 硬规则（按优先级）

1. **版式跟随内置模板**：页边距、字号、加粗、图片版心宽度由 `read_template_spec()` 从模板读出，代码里不写死数值。
2. **清空正文必须保留 `w:sectPr`**，否则页面尺寸退回 Letter。
3. **删图只能按「XML 实际引用的 rId 集合」反查回收**，绝不按段落逐个 `drop_rel`——同一张图可能复用同一 rId，逐个删会留下悬空引用（Word 里是红叉）。
4. **日期行保留模板原文标注**，如 `2025.10.11（发出日期）`。
5. **删除所有完全空的段落**（无文字、无图片）。
6. **gif 一律当装饰删除**，按文件头 `GIF8` 判定，别只信后缀。
7. **低清图当装饰删除**：最长边 < `--min-px` 或面积 < `--min-area`。
8. **图片下载要重试 + 原图回退**：`/640?` 被拒换 `/0?` 再试，最多 3 次。
9. **丢图必须报警**，终端与清单都要列出，不许静默跳过。
10. **标题栏目前缀统一 `||`**；文件名按固定规则 `yyyy.mm.dd(Title).docx` 生成，Title 去掉栏目前缀并剔除 Windows 非法字符。
11. **小标题要保留层级，不要拍平**。公众号小标题多为 `<section>` 内近乎全文加粗、短句、居中（如「活动第一项：升国旗，奏国歌」）。判定条件：长度 ≤40 字、句末不带 `。！？`、加粗覆盖率 ≥85%。命中后：**居中加粗**为一级小标题（正文字号 +1），**仅加粗不居中**为二级（正文字号）。误判时用 `--no-heading` 全部按正文输出。
12. **链接按出现顺序去重**。
13. **写入前探测占用**（`open(f,"r+b")`），被 Word/WPS 占用的跳过提示；`~$` 是锁文件，别删。

## 交付前自检

```bash
python <skill>/scripts/check_output.py --out "产物/10月"
```

要求全绿：`gif=0`、`empty=0`、`dangling=0`、图片尺寸均达标、首段为 `yyyy.mm.dd（发出日期）`。
任何一项不绿就不算完成。
